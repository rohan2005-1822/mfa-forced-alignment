# Forced alignment with Montreal Forced Aligner (MFA)

Word- and phone-level alignment of six utterances (3 Boston radio news recordings `F2BJRLP1-3`,
3 ISLE learner-English sentences) with MFA 3.4.4, the pretrained `english_us_arpa` acoustic model
and a dictionary extended by hand.

## Layout
```
data/raw/            original wav + transcripts as given (radio files are NIST SPHERE)
data/corpus/         MFA-ready corpus (plain WAV + cleaned .lab transcripts)
dictionary/          custom_additions.dict (5 manual entries), custom_full.dict (base + additions)
results/textgrids/   output TextGrids (word + phone tiers)
results/praat_screenshots/  Praat screenshots used in the report (plus two extra views)
results/figures/     matplotlib versions of the same views, generated by scripts/make_figures.py
results/alignment_summary.csv   per-file statistics;  results/alignment_analysis.csv  MFA's own quality metrics
scripts/             prepare_corpus.py, find_oov.py, build_dictionary.py, analyze_alignment.py, make_figures.py
run_pipeline.sh      runs everything end to end
report.pdf           short report
```

## Setup
```bash
conda create -n aligner -c conda-forge python=3.11 montreal-forced-aligner
conda activate aligner
pip install -r requirements.txt
```
(MFA cannot be installed with plain pip. Any machine with conda works; I ran it in a Kaggle notebook with micromamba.)

## Run
```bash
bash run_pipeline.sh data/raw
```
Steps: (1) convert NIST SPHERE wavs to RIFF WAV and clean transcripts, (2) download the models,
(3) list out-of-vocabulary words, (4) G2P suggestions for them, (5) build the custom dictionary,
(6) `mfa align`, (7) statistics and figures.

To inspect results, open a wav and its TextGrid together in Praat (select both, *View & Edit*).

## Transcript cleaning
Lowercase, punctuation removed, hyphens replaced by spaces (`seventy- six`, `de-politicize`),
`S.J.C.` written as `S J C`. Without this, MFA treats the hyphenated forms as unknown words.

## Custom dictionary
Words missing from `english_us_arpa`: dukakis, maffy, melnicove, politicize, wbur's.
G2P output was checked by hand; `wbur's` was replaced by the letter-by-letter reading
(W-B-U-R + s) because G2P treated it as an ordinary word.

## Notes
- `scripts/` (corpus preparation, OOV search, statistics, figures) were run on the real data.
  The MFA steps in `run_pipeline.sh` use the same commands that produced the shipped TextGrids,
  but the script as a whole has not been run end to end in a single go.
- Only `english_us_arpa` was used. A comparison with the `english_mfa` model was not done.
